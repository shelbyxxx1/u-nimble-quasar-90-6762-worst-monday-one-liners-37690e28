A tiny, deterministic entry about an AI agent whose Monday database migration needs legal counsel.

## Run it

```sh
python3 main.py
```

Uses only the Python standard library and is compatible with Python 3.13. Writes exactly 108 UTF-8 characters without a trailing newline to `/output/entry.txt`, or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set.
